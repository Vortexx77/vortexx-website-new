## 🎭 Animation Details

### Scroll Reveal System
**Intersection Observer-based:**
- Triggers when element is 10% visible
- Smooth cubic-bezier easing
- Staggered delays for groups
- Respects user motion preferences

### Hover Interactions
**Button Hovers:**
- Color transitions (500ms)
- Shadow expansion
- Vertical translation (-1px lift)
- Scale adjustments

**Card Hovers:**
- Scale: 1.02 - 1.05
- Shadow growth
- Border color shifts
- Content reveals

- Opacity crossfades (1000ms)

- Content slide-up animations

- **Label MD**: 14px, Semibold (600), 0.05em tracking

## 🎯 Responsive Breakpoints

### Mobile First Strategy
```
Mobile:   < 640px   (1 column, stacked)
Tablet:   640-768px (2 columns)
Desktop:  768-1024px (3-4 columns)
Large:    1024+px   (Full layout)
```

### Key Adjustments
- Font sizes scale down on mobile
- Grids collapse to fewer columns
- Padding/margins reduce proportionally
- Images adapt to container
- Navigation becomes hamburger menu

## ✨ Glassmorphism Effects

### Light Glass Panel
```css
background: rgba(255, 255, 255, 0.6)
backdrop-filter: blur(20px)
border: 1px solid rgba(255, 255, 255, 0.8)
box-shadow: subtle inset glow
```

### Dark Glass Panel
```css
background: rgba(25, 28, 30, 0.4)
backdrop-filter: blur(24px)
border: 1px solid rgba(255, 255, 255, 0.1)
box-shadow: deep shadow
```

**Used in:**
- Navigation bar
- Hero overlay cards
- Feature sections
- Modal dialogs
- Floating elements
